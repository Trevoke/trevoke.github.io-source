* You're not building a search engine. You're building a trust engine.
:PROPERTIES:
:CUSTOM_ID: the-confession-that-changes-everything
:END:
Here's what I wish I'd known when I started building RAG systems: you're
not building a search engine, you're building a *trust engine*. And trust
is measurable.

The failure mode is specific. You ask the system a question, it retrieves
some documents, and it hands back a confident, fluent answer that the
documents don't actually support. It looks right. It reads well. And it's
wrong --- the same way a confident answer in a meeting can be wrong,
except now it's wrong at scale and nobody's checking it against the
source. In RAG terms, that's a *faithfulness* problem: the answer drifted
away from the context it was supposed to be grounded in.

This tutorial builds a RAG system that can tell you when it's doing that.
And we'll know whether it works /before/ we write the implementation,
because we're going to write the tests first.

*Why we're using fantastical examples*: Throughout this tutorial, we'll
work with completely fictional concepts like "Zephyr Crystals" and
"Lumifruits." Why? Because when we use real-world examples, we can't
tell if the LLM is answering from its training data or from our RAG
system. With fantasy elements that no LLM has ever seen, we know with
100% certainty that every correct answer comes from our retrieval
system. It's the cleanest test of faithfulness I know: if the answer is
right, it came from your documents. Full stop.

* Why RAG needs quality measurement (and why you should care)
:PROPERTIES:
:CUSTOM_ID: why-rag-needs-quality-measurement-and-why-you-should-care
:END:
Let me tell you a story. A company I know built a customer service
chatbot using RAG. It worked great---until it started telling customers
that their refund policy included "a complimentary unicorn with every
return." The retrieval worked. The generation worked. But nobody
measured whether the generation was /faithful/ to what was retrieved.

Here's the catch: most RAG systems are built to look good in a demo, not
to be trustworthy in production. RAGAS is how you close that gap. It gives
you a fact-checker that asks three questions of every answer:

- "Did you actually find relevant information?" (Context Precision)
- "Did you use what you found honestly?" (Faithfulness)
- "Did you actually answer the question?" (Answer Relevancy)

In other words, RAGAS is what turns a RAG system from a creative writing
machine into something you can rely on.

#+begin_src python
import chromadb
import requests
import json
from typing import List, Optional, Dict, Any
from chromadb.api.types import EmbeddingFunction, Documents

class OllamaEmbeddingFunction(EmbeddingFunction):
    """
    Custom ChromaDB embedding function that uses Ollama's local embedding endpoint.
    """

    def __init__(self, model_name: str = "mxbai-embed-large", base_url: str = "http://localhost:11434"):
        self.model_name = model_name
        self.base_url = base_url
        self.embed_url = f"{base_url}/api/embeddings"
        self._embedding_dim = None  # We'll detect this

    def __call__(self, input: Documents) -> List[List[float]]:
        """
        Generate embeddings for a list of documents using Ollama.
        """
        embeddings = []

        for document in input:
            try:
                # Handle empty documents
                if not document or not document.strip():
                    print(f"Warning: Empty document, using placeholder")
                    # Use a placeholder for empty docs
                    document = "empty document placeholder"

                response = requests.post(
                    self.embed_url,
                    json={
                        "model": self.model_name,
                        "prompt": document
                    },
                    timeout=30
                )
                response.raise_for_status()

                embedding = response.json()["embedding"]

                # Detect embedding dimension on first successful call
                if self._embedding_dim is None:
                    self._embedding_dim = len(embedding)
                    print(f"Detected embedding dimension: {self._embedding_dim}")

                embeddings.append(embedding)

            except Exception as e:
                print(f"Error generating embedding for document: '{document[:50]}...': {str(e)}")
                # Fallback: return a zero vector of the expected dimension
                fallback_dim = self._embedding_dim or 1024  # mxbai-embed-large default
                embeddings.append([0.0] * fallback_dim)

        return embeddings

class VectorStore:
    def __init__(self, persist_directory="./chroma_db", in_memory=False):
        """
        Initialize ChromaDB with local Ollama embeddings.
        """
        if in_memory:
            # In-memory client - no files, no cleanup needed
            self.client = chromadb.Client()
        else:
            # Persistent client for production
            self.client = chromadb.PersistentClient(path=persist_directory)

        # Use our local Ollama embedding function
        self.embedding_function = OllamaEmbeddingFunction(
            model_name="mxbai-embed-large"
        )

        # Get or create our collection
        self.collection = self.client.get_or_create_collection(
            name="rag_documents",
            embedding_function=self.embedding_function
        )

    def add_documents(self, documents: List[str]) -> None:
        """Add documents to our vector store using local embeddings."""
        # Filter out empty documents
        valid_documents = []
        valid_ids = []

        for i, doc in enumerate(documents):
            if doc and doc.strip():  # Only add non-empty documents
                valid_documents.append(doc.strip())
                valid_ids.append(f"doc_{len(valid_documents)-1}_{hash(doc.strip()) % 10000}")

        if not valid_documents:
            print("Warning: No valid documents to add")
            return

        print(f"Adding {len(valid_documents)} documents to vector store...")
        self.collection.add(
            documents=valid_documents,
            ids=valid_ids
        )

    def search(self, query: str, k: int = 2) -> List[str]:
        """
        Search for similar documents using local embeddings.
        Returns empty list if no results or query issues.
        """
        # Handle empty or invalid queries
        if not query or not query.strip():
            print("Warning: Empty query provided")
            return []

        try:
            results = self.collection.query(
                query_texts=[query.strip()],
                n_results=min(k, self.collection.count())  # Don't ask for more than we have
            )

            # Handle case where no documents are returned
            if not results or not results.get('documents') or not results['documents'][0]:
                print(f"No results found for query: '{query}'")
                return []

            return results['documents'][0]  # ChromaDB returns nested lists

        except Exception as e:
            print(f"Error during search for query '{query}': {str(e)}")
            return []

    def search_with_scores(self, query: str, k: int = 2) -> List[Dict[str, Any]]:
        """
        Search with similarity scores for debugging.
        """
        if not query or not query.strip():
            return []

        try:
            results = self.collection.query(
                query_texts=[query.strip()],
                n_results=min(k, self.collection.count()),
                include=['documents', 'distances']
            )

            if not results or not results.get('documents') or not results['documents'][0]:
                return []

            # Combine documents with their scores
            documents = results['documents'][0]
            distances = results.get('distances', [None] * len(documents))[0]

            return [
                {
                    'document': doc,
                    'distance': dist,
                    'similarity': 1 - dist if dist is not None else None
                }
                for doc, dist in zip(documents, distances)
            ]

        except Exception as e:
            print(f"Error during scored search: {str(e)}")
            return []

    def get_collection_info(self) -> Dict[str, Any]:
        """Get info about the current collection for debugging."""
        try:
            count = self.collection.count()
            return {
                'document_count': count,
                'collection_name': self.collection.name
            }
        except Exception as e:
            return {'error': str(e)}

import litellm
from typing import Optional
import logging

# LiteLLM can be chatty. Let's keep it quiet unless we need it.
logging.getLogger("litellm").setLevel(logging.WARNING)

class LocalLLMClient:
    def __init__(self, base_url="http://localhost:11434", model_name="gemma3"):
        """
        Initialize connection to local LLM via Ollama.
        Ollama runs on port 11434 by default.
        """
        self.base_url = base_url
        # LiteLLM requires "ollama/" prefix for Ollama models
        self.model_name = f"ollama/{model_name}"

        # Configure LiteLLM for Ollama
        litellm.drop_params = True  # Ollama doesn't support all OpenAI params

    def complete(self, prompt: str, max_tokens: int = 150) -> str:
        """
        Send prompt to local LLM and return response.
        Simple interface, powerful results.
        """
        try:
            response = litellm.completion(
                model=self.model_name,
                messages=[{"role": "user", "content": prompt}],
                api_base=self.base_url,
                max_tokens=max_tokens,
                temperature=0.7,  # Some creativity, but not too much
            )
            return response.choices[0].message.content

        except Exception as e:
            # In production, you'd log this properly
            print(f"LLM connection error: {str(e)}")
            return f"Error: Could not connect to Ollama. Is it running on {self.base_url}?"

#+begin_src python
from typing import List, Dict, Any
from .vector_store import VectorStore
from .llm_client import LocalLLMClient

class RAGPipeline:
    def __init__(self, retrieval_k: int = 3, vector_store=None):
        """
        Initialize our RAG pipeline.
        retrieval_k: how many documents to retrieve for context
        vector_store: pass one in for tests (e.g. in-memory); defaults to a persistent store
        """
        self.vector_store = vector_store or VectorStore()
        self.llm_client = LocalLLMClient()
        self.retrieval_k = retrieval_k

    def add_documents(self, documents: List[str]) -> None:
        """Add documents to our knowledge base."""
        self.vector_store.add_documents(documents)

    def ask(self, question: str) -> str:
        """Simple interface: question in, answer out."""
        result = self.ask_with_context(question)
        return result["answer"]

    def ask_with_context(self, question: str) -> Dict[str, Any]:
        """
        The full RAG process:
        1. Retrieve relevant documents
        2. Build a prompt with context
        3. Generate an answer
        4. Return both answer and contexts (for transparency)
        """
        # Step 1: Retrieve relevant documents
        contexts = self.vector_store.search(question, k=self.retrieval_k)

        # Step 2: Build our prompt (this is where prompt engineering happens)
        prompt = self._build_prompt(question, contexts)

        # Step 3: Generate answer
        answer = self.llm_client.complete(prompt)

        # Step 4: Return everything (the answer plus the contexts it came from)
        return {
            "answer": answer,
            "contexts": contexts,
            "question": question
        }

    def _build_prompt(self, question: str, contexts: List[str]) -> str:
        """
        Build a prompt that encourages faithful answers.
        This is where the prompt does the work of keeping answers grounded.
        """
        context_text = "\n\n".join(contexts)

        prompt = f"""You are a helpful assistant. Answer the question based ONLY on the provided context.
If the context doesn't contain enough information to answer the question, say "I don't have enough information to answer that."

Context:
{context_text}

Question: {question}

Answer: """

        return prompt

#+begin_src python
from typing import Dict, Any, List
import asyncio
from ragas import SingleTurnSample
from ragas.metrics import Faithfulness, ResponseRelevancy, ContextPrecision
from ragas.llms import LangchainLLMWrapper
from ragas.embeddings import LangchainEmbeddingsWrapper
from ragas.run_config import RunConfig
from ragas.metrics.base import MetricWithLLM, MetricWithEmbeddings
from langchain_community.chat_models import ChatOllama
from langchain_community.embeddings import OllamaEmbeddings

class QualityEvaluator:
        def __init__(self, llm_name="gemma3", embedding_model_name="mxbai-embed-large"):
                """
                Initialize RAGAS metrics with our local LLM.
                This is where RAGAS meets our local setup.
                """
                chat_ollama = ChatOllama(
                    model=llm_name,
                    base_url="http://localhost:11434"
                )

                ollama_embeddings = OllamaEmbeddings(
                    model=embedding_model_name,
                    base_url="http://localhost:11434"
                )
                self.llm = LangchainLLMWrapper(chat_ollama)
                self.embeddings = LangchainEmbeddingsWrapper(ollama_embeddings)

                self.faithfulness = Faithfulness()
                self.relevancy = ResponseRelevancy()
                self.context_precision = ContextPrecision()

                metrics = [self.faithfulness, self.relevancy, self.context_precision]
                self._init_ragas_metrics(metrics, self.llm, self.embeddings)

        def _init_ragas_metrics(self, metrics, llm, embedding):
                """Initialize RAGAS metrics with LLM and embeddings."""
                for metric in metrics:
                   if isinstance(metric, MetricWithLLM):
                       metric.llm = llm
                   if isinstance(metric, MetricWithEmbeddings):
                       metric.embeddings = embedding
                       run_config = RunConfig()
                       metric.init(run_config)

        def evaluate_faithfulness(self, result: Dict[str, Any]) -> float:
                """
                Measure how faithful the answer is to the context.
                1.0 = perfect faithfulness, 0.0 = complete hallucination
                """
                sample = SingleTurnSample(
                        user_input=result["question"],
                        response=result["answer"],
                        retrieved_contexts=result["contexts"]
                )

                # Run async evaluation in sync context (RAGAS is async)
                score = asyncio.run(self.faithfulness.single_turn_ascore(sample))
                return float(score)

        def evaluate_relevancy(self, result: Dict[str, Any]) -> float:
                """
                Measure how relevant the answer is to the question.
                1.0 = perfectly relevant, 0.0 = completely off-topic
                """
                sample = SingleTurnSample(
                        user_input=result["question"],
                        response=result["answer"],
                        retrieved_contexts=result["contexts"]
                )

                score = asyncio.run(self.relevancy.single_turn_ascore(sample))
                return float(score)

        def evaluate_full_pipeline(self, results: List[Dict[str, Any]]) -> Dict[str, float]:
                """
                Evaluate a batch of results and return aggregate metrics.
                This is what you'd run on your test set.
                """
                faithfulness_scores = []
                relevancy_scores = []

                for result in results:
                        faithfulness_scores.append(self.evaluate_faithfulness(result))
                        relevancy_scores.append(self.evaluate_relevancy(result))

                return {
                        "average_faithfulness": sum(faithfulness_scores) / len(faithfulness_scores),
                        "average_relevancy": sum(relevancy_scores) / len(relevancy_scores),
                        "min_faithfulness": min(faithfulness_scores),
                        "min_relevancy": min(relevancy_scores),
                        "num_samples": len(results)
                }

from typing import List, Dict, Any, Optional
from .vector_store import VectorStore
from .llm_client import LocalLLMClient
import re

class ImprovedRAGPipeline:
    def __init__(self, retrieval_k: int = 3, rerank: bool = True, vector_store=None):
        """
        Improved RAG with better retrieval and prompt engineering.
        """
        self.vector_store = vector_store or VectorStore()
        self.llm_client = LocalLLMClient()
        self.retrieval_k = retrieval_k
        self.rerank = rerank

    def add_documents(self, documents: List[str], chunk_size: int = 200) -> None:
        """
        Add documents with smart chunking.
        Overlapping chunks improve context preservation.
        """
        chunked_docs = []
        for doc in documents:
            chunks = self._chunk_document(doc, chunk_size, overlap=50)
            chunked_docs.extend(chunks)

        self.vector_store.add_documents(chunked_docs)

    def _chunk_document(self, doc: str, chunk_size: int, overlap: int) -> List[str]:
        """
        Smart chunking that respects sentence boundaries.
        Keeping chunks coherent (not split mid-sentence) helps faithfulness.
        """
        sentences = re.split(r'(?<=[.!?])\s+', doc)
        chunks = []
        current_chunk = []
        current_size = 0

        for sentence in sentences:
            sentence_size = len(sentence.split())

            if current_size + sentence_size > chunk_size and current_chunk:
                chunks.append(" ".join(current_chunk))
                # Overlap: keep last few sentences
                overlap_size = 0
                overlap_chunk = []
                for sent in reversed(current_chunk):
                    overlap_size += len(sent.split())
                    overlap_chunk.insert(0, sent)
                    if overlap_size >= overlap:
                        break
                current_chunk = overlap_chunk
                current_size = overlap_size

            current_chunk.append(sentence)
            current_size += sentence_size

        if current_chunk:
            chunks.append(" ".join(current_chunk))

        return chunks

    def ask_with_context(self, question: str) -> Dict[str, Any]:
        """
        Improved RAG with reranking and better prompts.
        """
        # Step 1: Retrieve more documents than needed
        contexts = self.vector_store.search(
            question,
            k=self.retrieval_k * 2 if self.rerank else self.retrieval_k
        )

        # Step 2: Rerank if enabled (poor man's reranking with LLM)
        if self.rerank and len(contexts) > self.retrieval_k:
            contexts = self._rerank_contexts(question, contexts)[:self.retrieval_k]

        # Step 3: Build improved prompt
        prompt = self._build_improved_prompt(question, contexts)

        # Step 4: Generate with constraints
        answer = self.llm_client.complete(prompt, max_tokens=200)

        # Step 5: Post-process to improve faithfulness
        answer = self._post_process_answer(answer, contexts)

        return {
            "answer": answer,
            "contexts": contexts,
            "question": question
        }

    def _rerank_contexts(self, question: str, contexts: List[str]) -> List[str]:
        """
        Use LLM to rerank contexts by relevance.
        This significantly improves context precision.
        """
        rerank_prompt = f"""Given the question: "{question}"

Rank these contexts from most to least relevant:

{chr(10).join([f"{i+1}. {ctx}" for i, ctx in enumerate(contexts)])}

Return just the numbers in order of relevance, separated by commas."""

        ranking_response = self.llm_client.complete(rerank_prompt, max_tokens=50)

        try:
            # Parse ranking (e.g., "3,1,4,2" -> [3,1,4,2])
            ranking = [int(x.strip())-1 for x in ranking_response.split(",")]
            reranked = [contexts[i] for i in ranking if i < len(contexts)]
            return reranked if reranked else contexts
        except:
            # If parsing fails, return original order
            return contexts

    def _build_improved_prompt(self, question: str, contexts: List[str]) -> str:
        """
        Better prompt that emphasizes faithfulness.
        The trick is to be explicit about what NOT to do.
        """
        context_text = "\n\n".join([f"Context {i+1}: {ctx}" for i, ctx in enumerate(contexts)])

        prompt = f"""You are a helpful assistant that answers questions ONLY based on the provided context.

IMPORTANT RULES:
1. Use ONLY information from the provided context
2. If the context doesn't contain the answer, say "The provided context doesn't contain this information."
3. Do not add information from your general knowledge
4. Quote or paraphrase the context when possible
5. Keep your answer concise and directly related to the question

Context:
{context_text}

Question: {question}

Answer (based only on the context above): """

        return prompt

    def _post_process_answer(self, answer: str, contexts: List[str]) -> str:
        """
        Clean up the answer to improve quality metrics.
        Remove obvious hallucinations and off-topic content.
        """
        # Remove common LLM habits that hurt metrics
        answer = answer.strip()

        # Remove "Based on the context..." preambles
        preamble_patterns = [
            r"^Based on the (provided )?context,?\s*",
            r"^According to the (given )?information,?\s*",
            r"^From the context,?\s*"
        ]
        for pattern in preamble_patterns:
            answer = re.sub(pattern, "", answer, flags=re.IGNORECASE)

        # If answer is too long, truncate at sentence boundary
        if len(answer.split()) > 100:
            sentences = re.split(r'(?<=[.!?])\s+', answer)
            truncated = []
            word_count = 0
            for sent in sentences:
                word_count += len(sent.split())
                if word_count > 100:
                    break
                truncated.append(sent)
            answer = " ".join(truncated)

        return answer.strip()

* The lessons learned (what I wish I'd known)
:PROPERTIES:
:CUSTOM_ID: the-lessons-learned-what-i-wish-id-known
:END:
1. *Start with the test*: Every objective began with a test. The test
   told us what success looked like before we wrote a single line of
   implementation.

2. *Measure everything*: RAGAS isn't just about catching problems---it's
   about understanding your system's behavior. Low faithfulness? Your
   prompt needs work. Low relevancy? Your retrieval needs tuning.

3. *Simple first, clever later*: Our first implementation was
   deliberately simple. We added reranking and smart chunking only after
   we could measure their impact.

4. *Transparency builds trust*: Showing contexts and quality scores
   isn't just for debugging---it helps users understand when to trust
   the system.

5. *Local LLMs are liberating*: No API keys, no rate limits, no privacy
   concerns. Just you and your machine.

6. *Fantasy content is the ultimate test*: By using completely fictional
   concepts, we remove any possibility of the LLM answering from its
   training. Every correct answer about Zephyr Crystals or Lumifruits is
   proof that your RAG is working. Every hallucination is immediately
   obvious because the LLM literally cannot know these things without
   your documents.

* Where to go from here
:PROPERTIES:
:CUSTOM_ID: where-to-go-from-here
:END:
Your RAG system now has a quality measurement built in. But this is just
the beginning. You could:

1. *Add more sophisticated reranking*: Use cross-encoder models for
   better context selection
2. *Implement query understanding*: Classify questions to use different
   retrieval strategies
3. *Add memory*: Store conversation history for context-aware responses
4. *Build evaluation datasets*: Create test sets specific to your domain
5. *Optimize for speed*: Batch processing, caching, and async operations

The best RAG system isn't the one with the fanciest features. It's the
one that knows its limitations and tells you about them honestly.

A system that says "I don't know" when it doesn't know isn't broken ---
that's the whole point. That's trust.

So go build RAG systems that know when they're working and, more
importantly, when they're not.

/P.S. If your RAGAS scores are still low after all this, don't worry ---
mine were too. Going from 0.6 to 0.8 faithfulness taught me more about RAG
than any tutorial ever could. That's the real lesson: measurement isn't
judgment, it's education./

* Troubleshooting Ollama
:PROPERTIES:
:CUSTOM_ID: troubleshooting-ollama
:END:
Because I've been there, here are the common "why isn't it working?"
moments:

*"Connection refused" errors*: - Is Ollama actually running? Check with:
=curl http://localhost:11434/api/tags= - Solution: =ollama serve=

*"Model not found" errors*: - Did you pull the model? Check with:
=ollama list= - Solution: =ollama pull llama2= (or whatever model you
want)

*Slow responses*: - First run is always slow (model loading) - Consider
smaller models for development: =ollama pull phi= or
=ollama pull orca-mini=

*Out of memory*: - Ollama needs a few GB of RAM per model - Try smaller
models or close other applications

Local LLMs need a little attention up front, but once they're running
they stay out of your way --- no API keys, no internet required.
